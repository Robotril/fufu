# JB vs RD

A tiny two-character fighting game. Open `index.html` or host it on GitHub Pages.

## Host on GitHub Pages
1. Create a repo and upload everything in this folder (`index.html` and the `audio` folder).
2. Repo Settings > Pages > Deploy from branch > `main` / root.
3. Your game appears at `https://<username>.github.io/<repo>/`.

## Controls
| | JB (green, computer power) | RD (black, water power) |
|---|---|---|
| Move | A / D | Left / Right |
| Jump | W | Up |
| Punch | F | K |
| Kick | G | L |
| Power | H (ERROR.EXE freezes the enemy) | ; (Tidal Wave) |

Power costs half the meter. Land or take hits to fill it. M mutes, Esc returns to the menu.

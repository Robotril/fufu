# JB vs RD

A tiny two-character fighting game. Open `index.html` or host it on GitHub Pages.

## Host on GitHub Pages
1. Create a repo and upload everything in this folder (`index.html` and the `audio` folder).
2. Repo Settings > Pages > Deploy from branch > `main` / root.
3. Your game appears at `https://<username>.github.io/<repo>/`.

## Controls
**Phone or tablet:** on-screen buttons appear under the game (move, Jump, Attack, Blast, Ultimate). You play JB against the CPU.

**Keyboard**

| | JB (green, computer power) | RD (black, water power) |
|---|---|---|
| Move | A / D | Left / Right |
| Jump | 3 or W | Up |
| Attack | 1 (chains punch, punch, kick) | |
| Punch / Kick | F / G | K / L |
| Blast | 2 or H | ; |
| Ultimate | 4 or R | ' (apostrophe) |

In 1 Player mode either set of keys controls JB. M mutes, Esc returns to the menu.

## Powers
- **Blast** costs half the blue/green power bar, which refills over time.
  - JB: ERROR.EXE, a fake error window that freezes the enemy.
  - RD: Tidal Wave, which hits hard and knocks the enemy back.
- **Ultimate** needs the gold bar full. It fills as you hit and get hit.
  - JB: SYSTEM CRASH, a giant error screen that freezes the enemy for over a second.
  - RD: TSUNAMI, a huge wave that sends the enemy flying.
  - Ultimates cannot be jumped over and beat normal blasts. Getting hit while charging cancels one.
